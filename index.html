Featured · New

Workforce AI Security

As employees increasingly turn to AI tools to do their jobs faster, organizations face a growing governance gap: AI applications and agents now touch enterprise data, invoke tools, and take actions with a level of autonomy that traditional security controls weren't built to handle. Sensitive information can move through prompts, uploaded files, and AI-generated outputs in ways that bypass conventional data loss prevention. At DS2 Global, we help organizations close this gap — establishing clear policies for which AI tools and models are approved, controlling what data and systems employees' AI usage can reach, and applying consistent, real-time oversight across your workforce so AI adoption strengthens productivity without becoming your next breach vector.

For partners — going live

GitHub + Google Sheets, wired the same way as silaswandera.com.

This demo is one HTML page plus its hero photo — two files, nothing else to install. Two short setups take it live: host it from the DS2 Global GitHub repository, and point the form at a Google Sheet in the DS2 Global folder in Control Center HQ.

1 · Publish from GitHub

  1. Create a repository named ds2global (or use the existing DS2 Global repo).
  2. Add this page as index.html at the repo root — use the download button below to grab the exact file.
  3. In the repo: Settings → Pages → Deploy from branch → main / root.
  4. Add the custom domain ds2global.com under Pages once DNS is ready.
Current live site ↗

Commit the hero photo alongside it as assets/hero-soc.jpg so the image path resolves in the repo.

2 · Connect leads to Google Sheets

Create a sheet named DS2 Global — Website Leads in the DS2 Global folder in Control Center HQ, with these columns in row 1:

  • Timestamp · Name · Email · Company · Size · Interest · Preferred date · Time · Message · Status · Source
  1. In the sheet: Extensions → Apps Script, paste the script below, and deploy it as a Web App (access: anyone).
  2. Paste the Web App URL here and save — new leads will post to the sheet as they arrive.

Not connected yet — leads are held on this page and exportable as CSV until the URL is saved.

// DS2 Global — Website Leads · Apps Script receiver
// Sheet columns (row 1): Timestamp | Name | Email | Company | Size |
// Interest | Preferred date | Time | Message | Status | Source
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var d = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(), d.name || "", d.email || "", d.company || "",
    d.size || "", d.interest || "", d.date || "", d.time || "",
    d.message || "", "New", d.source || "ds2global demo site"
  ]);
  return ContentService
    .createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}
